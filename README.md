# Job Listings Web Scraper

This project scrapes only Python,Data and ML-related jobs and listing them 
from the Real Python Fake Jobs website

## Features
- Scrapes job title, company, location, posted date, and apply link
- Filters Python / Data / ML jobs
- Stores data in a Pandas DataFrame
- Exports cleaned data to CSV

## Tech Stack
- Python
- Requests
- BeautifulSoup
- Pandas

## Output
- jobs.csv

## What I Learned
- Handling HTML parsing with BeautifulSoup
- Filtering data using Python
- Building a complete scraping pipeline
